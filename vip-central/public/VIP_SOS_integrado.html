Próxima etapa para uso real

Para uma central remota receber o SOS automaticamente, será necessário hospedar uma API segura e um painel autenticado, configurar notificações e testar em dois aparelhos. Este arquivo, sozinho, é um protótipo funcional local e não garante monitoramento 24 horas.
