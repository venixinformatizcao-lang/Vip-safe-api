Proteção pessoal e resposta a emergências

Interface para o cliente VIP enviar um alerta e compartilhar informações com a central. Configure o endereço de uma API segura para habilitar o envio pela internet.

Esta versão HTML pode abrir alertas e preparar mensagens, mas a central só receberá alertas pela internet quando houver um servidor/API real configurado e testado. Não use esta demonstração como único meio de pedir socorro.

Formato esperado da API

O sistema enviará uma requisição HTTP POST em JSON com tipo do evento, cliente, horário, localização disponível, telefone e identificador aleatório da ocorrência. A API deve usar HTTPS, autenticar o dispositivo, validar dados, registrar a entrega e responder com status 2xx.

POST /api/alerts
Content-Type: application/json
Authorization: Bearer [token]

{
  "type": "SOS",
  "client": "VIP 001",
  "event_id": "...",
  "timestamp": "...",
  "location": {
    "latitude": 0,
    "longitude": 0,
    "accuracy_m": 0
  }
}

Não compartilhe o token. A produção precisa de login, permissões, proteção contra abuso, logs de auditoria e política de privacidade.
